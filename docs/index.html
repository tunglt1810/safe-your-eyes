Safe Your Eyes

AI writes the code. You forget to blink. This app taps you on the shoulder, makes you close your eyes for a bit, then hands you back to your work.

Windows · macOS · Linux (x86_64 & ARM64) GPL-2.0-only
Download Star on GitHub

Latest:

Tiny breaks, zero drama

15 seconds every 15 minutes, a whole minute every 75. It warns you first, then locks the keys for 2 seconds so your fingers can't skip it out of habit.

Knows when to hush

Walk away and it stops counting. It also saves the reminder for later while you're fullscreen or on battery.

Featherweight

Your computer will barely notice it. It only shows up when it's break time.

No admin password

Installs into your own account. No IT ticket needed.

Settings

Make breaks longer, or space them out, right here. The window follows your light or dark mode.

Code Signing Policy

Windows packages distributed through the Microsoft Store are signed by Microsoft. Standalone downloads on GitHub Releases are built from this repository by GitHub Actions with SHA-256 checksums and VirusTotal scans.

  • Open: The source is on GitHub. GitHub builds every download from it, and each one is scanned on VirusTotal.
  • Maintainer: @tunglt1810 writes, reviews and approves every change.
  • License: Open source under GPL-2.0-only.

Privacy Policy

This program does not transfer personal information or telemetry to networked systems. When automatic update checks are enabled (configurable in Settings) or when you manually check for or install an update, the program sends HTTPS requests to GitHub Releases solely to check for and download new versions.
